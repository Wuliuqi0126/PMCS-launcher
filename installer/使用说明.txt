PMCS launcher 1.16.0

感谢安装 PMCS launcher。安装完成后可以从桌面或开始菜单启动。

主要功能
--------
- 官方版本库：下载 Mojang 正式版、快照与远古版本。
- 原版 / Fabric / Forge 实例，每个实例独立存档、模组和配置。
- 实例模组设置：按实例启停已下载的模组、光影包和资源包。
- Modrinth 模组市场，自动安装前置依赖。
- 游戏内中文：启动前自动写入简体中文语言设置。
- 游戏内启动器名称显示为「PMCS launcher」。
- 局域网联机：同一 Wi-Fi/热点下自动发现房间，并内置完整联机指引。
- 局域网共享存档：自动识别本机存档，主机共享后客机可自动发现并下载导入。
- 主页“推荐”：关闭主机正版验证、一键安装性能优化模组、下载 Java 21、打开存档共享。
- 局域网正版验证修复：客机提示“无效会话”时，主机可一键安装 OfflineLAN，或自动修改独立服务端的 server.properties。
- 离线账号与微软账号登录。
- 三源自动测速下载：Mojang 官方 / BMCLAPI / FastMinecraftMirror。
- 256 线程并发下载，最多 64 路分片，支持断点续传、动态切换镜像和 SHA-512/SHA-256/SHA-1 校验。
- Tailscale 官方安装包已内置，首次安装外网联机无需再下载 37MB 包体。
- playit.gg 隧道组件已内置，可选择不安装 VPN 的外网联机方式。
- 卸载时可选择删除游戏资源、配置，并默认一并卸载 Tailscale。
- Java 自动检测与下载。

使用提示
--------
- 安装包未签名，Windows SmartScreen 可能提示，请选择“更多信息 → 仍要运行”。
- 游戏数据默认在 %APPDATA%\.oasis，卸载启动器不会删除游戏数据。
- 选择父文件夹后安装到其下 PMCS launcher 子目录；检测到旧安装会自动使用原目录覆盖更新，用户数据保留。
- 局域网联机需要主机在游戏内按 Esc → 对局域网开放。
- 下载源默认自动测速；也可以在设置中手动锁定。
- 模组设置里的光影包/资源包启用后，还需要在游戏内对应菜单选择。
- 实例运行中不能切换模组，请先退出游戏。
